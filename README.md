# Alía

Marketplace de servicios que conecta personas que necesitan resolver una necesidad con profesionales que pueden ofrecer un servicio para solucionarla.

## Estado actual

En desarrollo — Alía 1.0 (MVP). Ver roadmap y bitácora del proyecto para más detalle.

## Stack

- Frontend: React Native + Expo + TypeScript
- Backend: Supabase (PostgreSQL, Auth, Storage)
- Estado global: Zustand
- Navegación: Expo Router
